# Eigenes Logo (optional)

Hier kann ein eigenes Logo abgelegt werden. Die Anwendung verwendet es
automatisch in der Navigationsleiste und auf der Anmeldeseite. Ohne
Logo-Datei erscheint der Schriftzug „Agile Board“.

Erkannte Dateinamen (in dieser Reihenfolge):

1. `logo.svg` (empfohlen, gestochen scharf in jeder Größe)
2. `logo.png`
3. `logo.webp`
4. `logo.jpg`

Hinweise:

- Das Logo wird auf dunklem Hintergrund angezeigt; eine Variante mit heller
  Schrift bzw. transparentem Hintergrund verwenden.
- Anzeigehöhe ca. 32 px; für PNG mindestens 96 px Höhe liefern.
- Nach dem Hinzufügen den Entwicklungsserver neu laden; in Produktion
  `python manage.py collectstatic` ausführen.
