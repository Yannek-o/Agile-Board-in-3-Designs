Schnellstart

Token im Header Authorization: Bearer … mitsenden. Antworten sind JSON; es gelten dieselben Projektrechte wie in der Oberfläche.

GET   /api/v1/projects/
GET   /api/v1/projects/<KEY>/items/?status=todo&limit=50
POST  /api/v1/projects/<KEY>/items/
GET   /api/v1/projects/<KEY>/items/<nr>/
PATCH /api/v1/projects/<KEY>/items/<nr>/
GET   /api/v1/projects/<KEY>/sprints/
curl -H "Authorization: Bearer ab_…" \
  -X PATCH -H "Content-Type: application/json" \
  -d '{"status": "done", "version": 4}' \
  {{ request.scheme }}://{{ request.get_host }}/api/v1/projects/HELP/items/5/
